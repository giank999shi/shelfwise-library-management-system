# School Library Management System (Java + Spring Boot + MySQL)

**Start here: open `GUIDE.md`**. It has the full step-by-step instructions to install, run, and use the system.

Quick version:
1. Install JDK 17+, MySQL 8, and IntelliJ IDEA.
2. Open this folder in IntelliJ and wait for Maven to finish.
3. Put your MySQL password in `src/main/resources/application.properties`.
4. Run `LibraryApplication` and open http://localhost:8080
5. Log in with `admin` / `admin123`.
